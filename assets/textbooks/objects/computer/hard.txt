The other options are either factually incorrect (A, C) or irrelevant to the conceptual leap (D).

Answer: C

8. In a modern multi-core CPU, L1 cache is typically private to each core, while L3 cache is shared among all cores. What is the most likely reason for this design choice in the memory hierarchy?

Explanation: L1 cache is the fastest and smallest cache, designed to be accessed with minimal latency by a single core.   IF x MOD 2 == 0 THEN
    total = total + x
  ELSE
    CONTINUE
  ENDIF
  count = count + 1
ENDFOR


A) 10
B) 5
C) 30
D) 0

Explanation: The question tests the understanding of the CONTINUE statement.
The loop iterates from x = 1 to 10.

Therefore, count will be incremented 5 times. The final value of total would be 30, which is a distractor.

291. What is the primary purpose of adding a "salt" when hashing a password?
A) To make the hash shorter.
B) To make the hashing process faster.
C) A salt is a unique, random string added to the password before hashing. It ensures that two users with the same password will have different hashes, which defeats pre-computed "rainbow table" attacks.
D) The salt is a secret key known only to the server, used for decrypting the hash.

Answer: C
Explanation: If two users choose the same common password, like "password123", they would have the identical hash in the database. An attacker who steals the database can pre-compute the hashes of all common passwords (a "rainbow table") and instantly know the password for every user who used one. By adding a unique, randomly generated salt to each user's password before hashing (hash(password + salt)), you ensure that even if two users have the same password, their stored hashes will be completely different. This forces an attacker to crack each password individually, rendering rainbow tables useless. D is incorrect; hashes cannot be decrypted.
